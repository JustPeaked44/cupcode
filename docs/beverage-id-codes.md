# FY25 Beverage Resource Manual

## Appendix — Beverage ID Codes

Transcribed from the four supplied manual images. Sections are organized by their relationships: modifier and attribute fields first, then drink categories. Within each source list, entries follow the printed order, reading the left column before the right column.

### Reading conventions

- A code is interpreted within its ID field and category. Identical codes in different fields or categories must not be treated as interchangeable.
- `Shown normally` describes an entry's appearance in the source; it does not assert current availability.
- `Crossed out in source` identifies a visibly struck-through code. Its printed meaning is retained without inferring an operational status.
- Wording, capitalization, and spacing are lightly normalized only where the meaning is unchanged. Trademark symbols are omitted.
- Repeated source entries and special combined-code examples are preserved.
- Empty outlined boxes in the images identify ID fields; they are represented below by explicit **ID field** labels.

- Place `Lt` before the code being modified to mean Light.
- Place `X` before the code being modified to mean Extra.

- The two `WC` rows are separate source entries: Whipped Cream is shown normally; the code beside No Whipped Cream is crossed out.
