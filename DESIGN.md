# CupCode

Independent, calm barista self-study tool. The supplied Apple-inspired direction leads: system typography, green #176448, near-white #F7F9F8, immediate pressed feedback, visible focus, brief opacity transitions, reduced motion/transparency support. No scores, timers, accounts or persistence.

Signature: large editable cup markings and a quiet order-ticket treatment. Homepage pairs oversized purpose-led typography with a custom CSS cup illustration. Practice prioritizes the dialogue, six marking fields and answer action. Full codes live in a searchable reference view. Mobile cups remain full size in a labeled snap-scroll workspace.
